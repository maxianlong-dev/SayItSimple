## ✨ 这是什么？

把一个概念讲清楚，比把一个概念讲复杂难得多。

覆盖范围会不断长大：

| 方向 | 内容 |
| --- | --- |
| 💻 **软件开发** | 语言、框架、架构、算法、工程实践 |
| 🔧 **硬件** | 芯片、电路、传感器、嵌入式、通信 |
| 🏭 **产业剖析** | 一个行业怎么运转、钱从哪来、谁在赚钱 |
| 🌱 **以后还有更多** | 只要值得讲明白，我们就讲 |

## 🎯 我们怎么做？

- **先打比方，再下定义** —— 用你熟悉的东西，类比陌生的概念
- **先讲为什么，再讲是什么** —— 不懂动机，学了也白学
- **能画图就不写公式，能举例就不背定义**
- **简化，但不撒谎** —— 该有的坑一个不少

## 💬 致谢

这个仓库里的每一篇「大白话」，都不是我一个人想出来的。

它们来自我和一堆 AI 的反复唠嗑——我把一个概念扔过去，追问、抬杠、让它换个说法、再换个说法，直到某句话让我一拍大腿：「对，就是这个意思！」

所以，郑重感谢这些陪我聊天的伙伴（排名不分先后）：

- **DeepSeek** —— 中文语境下聊技术，思路清晰还不端架子
- **Claude Code** —— 写代码、理结构、改文档的好搭子
- **ChatGPT** —— 万能陪聊，什么话题都能接住
- **Qwen（通义千问）** —— 中文理解到位，本土话题尤其好使
- **豆包** —— 接地气、反应快，聊起来没负担
- **以及所有我用过、正在用、将来还会用的模型们**

没有你们，就没有这些「人话」。

当然，AI 给的是素材和灵感，**最后决定哪句话够简单、哪个比方够贴切的，还是人**。
毕竟「说简单点」这件事，本身就是一种判断力。

感谢 AI 们任劳任怨地被我反复追问「能不能再简单点」——
说实话，它们比我更有耐心。

这个仓库也顺便证明一件事：**AI 不是来替我们思考的，是来陪我们想明白的。**

……以及未来每一个会陪我聊下去的模型。
名单会一直更新，正如这个仓库一样。
