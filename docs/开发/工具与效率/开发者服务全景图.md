# 开发者服务全景图
---
## 🏗️ 按你省掉的工作量排列（从少到多）
```plain text
你管的越来越少 ↓

┌─────────────────────────────────────────────────┐
│  IaaS — 基础设施即服务                            │  你管：OS、运行时、代码、数据
│  给你虚拟机/网络/存储，剩下你自己搞                  │
├─────────────────────────────────────────────────┤
│  CaaS / PaaS — 容器/平台即服务                    │  你管：代码、数据
│  给你运行环境，不用管机器                            │
├─────────────────────────────────────────────────┤
│  BaaS — 后端即服务                               │  你管：前端代码
│  给你现成的后端 API（数据库/认证/存储）                │
├─────────────────────────────────────────────────┤
│  FaaS — 函数即服务                               │  你管：单个函数
│  写一个函数，平台帮你运行                            │
├─────────────────────────────────────────────────┤
│  SaaS — 软件即服务                               │  你管：配置
│  直接用别人的成品软件                               │
└─────────────────────────────────────────────────┘
```
---
## 1️⃣ IaaS — 基础设施即服务
> 给你虚拟机、网络、硬盘，相当于"云上机房"
| 服务 | 说明 |
| --- | --- |
| **AWS EC2** | 行业标杆 |
| **阿里云 ECS** | 国内第一 |
| **Google Compute Engine** | GCP 的算力层 |
| **Azure VMs** | 微软系 |
| **Vultr / Hetzner / DigitalOcean** | 便宜好用的小厂 |
**适合：** 要完全控制、跑自定义架构、大规模集群
---
## 2️⃣ PaaS — 平台即服务
> 你推代码，平台帮你构建、部署、运行，不碰服务器
| 服务 | 特点 |
| --- | --- |
| **Heroku** | PaaS 鼻祖，`git push` 部署，2024 后涨价不少 |
| **Railway** | 现代版 Heroku，DX 极好，Docker/Postgres 一键起 |
| **Render** | Heroku 平替，免费层友好 |
| [**Fly.io**](http://fly.io/) | 容器跑在全球边缘节点，延迟低 |
| **Google App Engine** | Google 的老牌 PaaS |
| **阿里云 SAE** | Serverless 应用引擎 |
**适合：** 有自己的后端代码，但不想管服务器
---
## 3️⃣ BaaS — 后端即服务（你已经知道的）
> 不写后端代码，平台提供数据库 + 认证 + 存储 + API
Firebase、Supabase、Appwrite、PocketBase...
---
## 4️⃣ FaaS — 函数即服务（Serverless Functions）
> 写一个函数，触发就跑，按调用次数收费，空闲不花钱
| 服务 | 说明 |
| --- | --- |
| **AWS Lambda** | 开创者，生态最大 |
| **Cloudflare Workers** | V8 隔离，冷启动几乎为零，全球边缘 |
| **Vercel Functions** | 前端部署顺带的 Serverless |
| **阿里云函数计算 FC** | 国内对标 Lambda |
| **Deno Deploy** | Deno 运行时，TS 原生 |
**适合：** API 网关、Webhook、定时任务、轻量后端
---
## 5️⃣ 前端托管 / Jamstack 平台
> 专注静态站点 + SSR 部署
| 服务 | 特点 |
| --- | --- |
| **Vercel** | Next.js 亲爹，前端部署体验天花板 |
| **Netlify** | Jamstack 先驱，表单/Identity/Edge Functions |
| **Cloudflare Pages** | 免费额度大方，配合 Workers 强 |
| **GitHub Pages** | 纯静态，免费，简单够用 |
---
## 6️⃣ DBaaS — 数据库即服务
> 只要一个托管数据库，不要整个后端
| 服务 | 数据库类型 |
| --- | --- |
| **PlanetScale** | MySQL，分支 + 无锁 schema 变更 |
| **Neon** | Serverless Postgres，按用量计费，秒级分支 |
| **Turso** | 分布式 SQLite（libSQL），嵌入式 + 边缘 |
| **MongoDB Atlas** | 托管 MongoDB |
| **Upstash** | Serverless Redis + Kafka |
| **阿里云 RDS / PolarDB** | 国内主流 |
**适合：** 有自己的后端代码，只想把数据库外包
---
## 7️⃣ Auth-aaS — 认证即服务
> 只要登录注册这一块
| 服务 | 特点 |
| --- | --- |
| **Auth0** (Okta) | 行业标杆，功能最全 |
| **Clerk** | DX 极好，React/Next.js 深度集成，2024-25 最火 |
| **WorkOS** | 面向 B2B，SSO/SCIM/Directory Sync |
| **Logto** | 开源，可自部署 |
| **Keycloak** | 老牌开源，企业级 |
---
## 8️⃣ CMS-aaS — 内容管理即服务（Headless CMS）
> 给你内容管理后台 + API，前端你自己写
| 服务 | 特点 |
| --- | --- |
| **Strapi** | 开源，Node.js，最流行 |
| **Sanity** | 实时协作，结构化内容 |
| **Contentful** | 企业级 Headless CMS |
| **Directus** | 套在任意 SQL 数据库上 |
| **Payload CMS** | TS 原生，代码优先 |
---
## 9️⃣ AI/ML-aaS
> AI 能力按 API 卖
| 服务 | 能力 |
| --- | --- |
| **OpenAI API / Claude API** | LLM 对话/生成 |
| **Replicate** | 跑开源模型（SD、Llama 等） |
| **Hugging Face Inference** | 模型托管 + 推理 |
| **Pinecone / Weaviate** | 向量数据库 |

## 完整生态一图流
```plain text
一个现代 App 可以这样拼：

┌─────────────────────────────────────┐
│         Vercel / Netlify            │  前端托管
├──────────┬──────────┬───────────────┤
│  Clerk   │ Supabase │  Cloudflare   │  认证 │ 数据库+存储 │ 边缘函数
├──────────┴──────────┴───────────────┤
│         Upstash (Redis/Kafka)       │  缓存/消息队列
├─────────────────────────────────────┤
│         Resend / Postmark           │  邮件服务
├─────────────────────────────────────┤
│         Stripe                      │  支付
├─────────────────────────────────────┤
│         Claude API / OpenAI         │  AI 能力
└─────────────────────────────────────┘

一行服务器代码没写，全拼起来的
```

## 怎么选？看你缺什么
| 你的情况 | 推荐方向 |
| --- | --- |
| 啥都不想管，只写前端 | **BaaS**（Supabase/Firebase） |
| 有后端代码，不想管服务器 | **PaaS**（Railway/Render） |
| 只需要数据库 | **DBaaS**（Neon/PlanetScale） |
| 只需要登录功能 | **Auth**（Clerk/Auth0） |
| 轻量 API / 事件驱动 | **FaaS**（Cloudflare Workers/Lambda） |
| 要完全掌控 | **IaaS**（EC2/ECS）+ 自己搭 |
现在的趋势是 **"可组合架构"（Composable Architecture）** —— 不用一个平台解决所有问题，而是每个维度挑最好的服务拼起来。BaaS 是其中最大的一块拼图，但不是唯一的选择。
