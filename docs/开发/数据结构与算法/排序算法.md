## 一、六大排序算法详解
### 1. 冒泡排序 (Bubble Sort)
**大白话**：像水里冒泡泡，大的数一步步往后挪。每轮比较相邻两个数，大的往后走，一轮下来最大的就跑到最后了。
```python
def bubble_sort(arr):
    n = len(arr)
    for i in range(n):
        for j in range(n - i - 1):
            if arr[j] > arr[j + 1]:
                arr[j], arr[j + 1] = arr[j + 1], arr[j]
    return arr

# [5,2,4,1] → [2,4,1,5] → [2,1,4,5] → [1,2,4,5]
```
**时间复杂度**：O(n²)，**稳定**。
---
### 2. 选择排序 (Selection Sort)
**大白话**：每轮从剩下的数里挑一个最小的，放到前面。像排队时老师每次点名把最矮的拎出来站前面。
```python
def selection_sort(arr):
    n = len(arr)
    for i in range(n):
        min_idx = i
        for j in range(i + 1, n):
            if arr[j] < arr[min_idx]:
                min_idx = j
        arr[i], arr[min_idx] = arr[min_idx], arr[i]
    return arr
```
**时间复杂度**：O(n²)，**不稳定**。
---
### 3. 插入排序 (Insertion Sort)
**大白话**：像打扑克摸牌，每摸一张就往手里已排好的牌里插到正确位置。
```python
def insertion_sort(arr):
    for i in range(1, len(arr)):
        key = arr[i]
        j = i - 1
        while j >= 0 and arr[j] > key:
            arr[j + 1] = arr[j]
            j -= 1
        arr[j + 1] = key
    return arr
```
**时间复杂度**：O(n²)，**稳定**。数据接近有序时特别快。
---
### 4. 快速排序 (Quick Sort)
**大白话**：随便挑一个数当"分界线"（pivot），比它小的丢左边，比它大的丢右边，然后左右两堆各自再这么搞。分而治之。
```python
def quick_sort(arr):
    if len(arr) <= 1:
        return arr
    pivot = arr[len(arr) // 2]
    left = [x for x in arr if x < pivot]
    mid = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]
    return quick_sort(left) + mid + quick_sort(right)
```
**时间复杂度**：平均 O(n log n)，最坏 O(n²)。工程上最常用。
---
### 5. 归并排序 (Merge Sort)
**大白话**：把数组一切两半，两半各自排好，再像拉链一样合起来。递归到底就是一个数，天然有序。
```python
def merge_sort(arr):
    if len(arr) <= 1:
        return arr
    mid = len(arr) // 2
    left = merge_sort(arr[:mid])
    right = merge_sort(arr[mid:])
    return merge(left, right)

def merge(left, right):
    result, i, j = [], 0, 0
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            result.append(left[i]); i += 1
        else:
            result.append(right[j]); j += 1
    result.extend(left[i:]); result.extend(right[j:])
    return result
```
**时间复杂度**：稳定 O(n log n)，**稳定排序**，但要额外空间。
---
### 6. 堆排序 (Heap Sort)
**大白话**：把数组搞成一个"大顶堆"（父节点比子节点大），堆顶就是最大的，把它拎出来放最后；剩下的重新整理成堆，再拎堆顶……循环。
```python
import heapq

def heap_sort(arr):
    heapq.heapify(arr)  # 小顶堆
    return [heapq.heappop(arr) for _ in range(len(arr))]
```
**时间复杂度**：O(n log n)，**不稳定**。

## 二、算法对比图
### 综合对照表
| 算法 | 大白话 | 时间(平均) | 时间(最坏) | 空间 | 稳定性 | 适用场景 |
| --- | --- | --- | --- | --- | --- | --- |
| 冒泡 | 泡泡往上冒，大数往后走 | O(n²) | O(n²) | O(1) | ✅ 稳定 | 教学演示 |
| 选择 | 每轮挑最小的往前放 | O(n²) | O(n²) | O(1) | ❌ 不稳定 | 交换成本高时 |
| 插入 | 摸牌插到手里已排好的位置 | O(n²) | O(n²) | O(1) | ✅ 稳定 | 小数据/近乎有序 |
| 快排 | 挑分界线，左小右大，递归 | O(n log n) | O(n²) | O(log n) | ❌ 不稳定 | 通用最快 |
| 归并 | 一切两半各自排，再拉链合并 | O(n log n) | O(n log n) | O(n) | ✅ 稳定 | 要求稳定 |
| 堆排 | 建大顶堆，堆顶拎走放末尾 | O(n log n) | O(n log n) | O(1) | ❌ 不稳定 | 空间紧张 |
### 选型决策图
```plain text
数据量 < 50 ?
├── 是 → 插入排序（常数小，够用）
└── 否 →
    要求稳定 ?
    ├── 是 → 归并排序
    └── 否 →
        内存紧张 ?
        ├── 是 → 堆排序
        └── 否 → 快速排序（工程首选）

生产环境：直接用语言内置（Python 的 Timsort = 归并 + 插入）
```
### 复杂度可视化
```plain text
时间复杂度增长曲线（n 越大差距越明显）

O(n²)   ████████████████████  冒泡、选择、插入
O(nlogn) █████                快排、归并、堆排
O(n)    ██                    (线性排序，如计数排序)
O(1)    ▏                     (理论下限)
```

## 三、快速记忆技巧
### 🎯 技巧 1：口诀记复杂度
> **"冒选插 n 方，快归堆 nlogn"**
- 三个 O(n²)：冒泡、选择、插入（简单粗暴的三兄弟）
- 三个 O(n log n)：快排、归并、堆排（进阶三剑客）
### 🎯 技巧 2：稳定性口诀
> **"冒插归 稳，选快堆 不稳"**
记忆窍门：**带"选"和"快"的通常不稳**（选择、快排、希尔），因为它们会"跳跃式"交换，容易打乱相同元素的原始顺序。
### 🎯 技巧 3：场景联想法（生活场景绑定）
| 算法 | 联想场景 | 关键动作 |
| --- | --- | --- |
| 冒泡 | 🫧 汽水里的气泡上浮 | 相邻交换 |
| 选择 | 🙋 老师点名挑最矮的站前面 | 找最小值 |
| 插入 | 🃏 打扑克整理手牌 | 找位置插入 |
| 快排 | ⚔️ 划一刀，左右分堆 | 分区递归 |
| 归并 | 🤝 两队合并成一队（拉链） | 拆分合并 |
| 堆排 | 🏔️ 每次搬走山顶最大石头 | 堆化取顶 |
### 🎯 技巧 4：分类记忆（按算法思想）
```plain text
排序算法
├── 基于比较交换
│   ├── 相邻比较：冒泡、插入
│   └── 全局比较：选择
├── 分治思想
│   ├── 快排（先分再排）
│   └── 归并（先排再合）
└── 数据结构辅助
    └── 堆排（用堆结构）
```
### 🎯 技巧 5：选型口诀
> **"小用插，稳用归，快用快，省内存用堆"**
- 数据 \< 50 → **插入**（常数小）
- 要稳定 → **归并**
- 通用最快 → **快排**
- 空间紧张 → **堆排**
### 🎯 技巧 6：手写代码"三步套路"
**冒泡 / 选择 / 插入** 都是双层循环，记住模板：
```plain text
外层管轮数，内层管比较，条件满足就交换/记录
```
**快排 / 归并** 都是递归，记住模板：
```plain text
1. 递归出口 (len <= 1)
2. 拆分数据
3. 递归处理 + 合并结果
```
