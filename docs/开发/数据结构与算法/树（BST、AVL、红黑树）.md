# 树（BST、AVL、红黑树）
> 从基础概念到 BST、AVL、红黑树的旋转与增删，一次讲透。
---
## 一、树是什么
**大白话**：倒着长的树。一个老祖宗（根）在顶上，往下不断分叉出子孙，**每个节点只有一个爹**（除了根没爹），也不能有环。
```plain text
        A          ← 根节点 (root)
       / \
      B   C
     /|   |\
    D E   F G      ← 叶子节点 (leaf)
```
**关键约束**：
- 有且只有**一个根**
- 每个节点**只有一个父节点**（根除外）
- **没有环**（不能绕回自己）
如果允许多个爹或有环，那就是"图"了，不是树。
---
## 二、核心术语
### 1. 节点 (Node)
树里的每个圆圈就是一个节点，装着数据和指向孩子的指针。
### 2. 根节点 (Root)
最顶上那个，**没有父亲**。整棵树的入口。
### 3. 父 / 子 / 兄弟节点
- **父 (Parent)**：某节点的上一级
- **子 (Child)**：某节点的下一级
- **兄弟 (Sibling)**：同一个爹的节点
### 4. 叶子节点 (Leaf)
**没有孩子的节点**，最末端的那些。
### 5. 非叶子节点 (Non-leaf) / 内部节点
**至少有一个孩子的节点**。
### 6. 度 (Degree)
**一个节点的孩子个数**。
- 叶子的度一定是 0
- **树的度** = 所有节点里最大的那个度
> 记忆：度 = "分叉数"
### 7. 深度 (Depth) 和 层 (Level)
**从根往下数**。根是第 1 层（或第 0 层，教材不一）。
某节点的深度 = 它到根经过的边数。
### 8. 高度 (Height)
**从叶子往上数**，方向与深度相反。
- 叶子高度 = 1（或 0）
- 树的高度 = 根的高度 = 最深叶子的深度
> **深度 vs 高度**：
	- 深度：从上往下看，这个节点在第几层
	- 高度：从下往上看，这个节点离最深叶子多远
	- 树的高度 = 树的深度
### 9. 子树 (Subtree)
任何一个节点连同它下面的所有子孙就是一棵子树。
### 10. 路径 & 祖先 / 后代
- 路径长度 = 两节点之间的边数
- 祖先 = 从根到某节点路径上的所有节点
- 后代 = 某节点子树里的所有节点
---
## 三、几种特殊的树
### 二叉树 (Binary Tree)
每个节点最多 2 个孩子（度 ≤ 2），分左孩子、右孩子。
### 满二叉树 (Perfect Binary Tree)
每一层都塞满。深度为 k 的满二叉树有 2\^k - 1 个节点。
```plain text
      1
     / \
    2   3
   /|   |\
  4 5   6 7
```
### 完全二叉树 (Complete Binary Tree)
除了最后一层其他层塞满；最后一层从左往右连续排（右边可以缺）。
```plain text
      1
     / \
    2   3
   /|   /
  4 5  6
```
堆就是用完全二叉树实现的，可以直接用数组存（不用指针）。
### 二叉搜索树 (BST)
每个节点：**左子树都比它小，右子树都比它大**。中序遍历得到有序序列。

## 四、树的遍历
**遍历 = 把每个节点都访问一遍**，分两大类。
以这棵树为例：
```plain text
      A
     / \
    B   C
   / \   \
  D   E   F
```
### 深度优先 DFS —— 用递归/栈
#### 前序 (Pre-order)：**根 → 左 → 右**
```plain text
A → B → D → E → C → F
```
**用途**：复制/序列化树、打印目录结构。
#### 中序 (In-order)：**左 → 根 → 右**
```plain text
D → B → E → A → C → F
```
**用途**：**BST 中序遍历得到有序序列**（黄金性质）。
#### 后序 (Post-order)：**左 → 右 → 根**
```plain text
D → E → B → F → C → A
```
**用途**：删除/释放树、算目录总大小、表达式树求值。
> **记忆法**：前中后指的是**根**的位置。左永远在右前面。
### 广度优先 BFS / 层序遍历 —— 用队列
**一层一层从左到右扫**：
```plain text
A → B → C → D → E → F
```
**用途**：找最短路径、按层处理、判断完全二叉树。
### 遍历代码模板
```python
# 前序
def pre_order(node):
    if not node: return
    visit(node)
    pre_order(node.left)
    pre_order(node.right)

# 中序
def in_order(node):
    if not node: return
    in_order(node.left)
    visit(node)
    in_order(node.right)

# 后序
def post_order(node):
    if not node: return
    post_order(node.left)
    post_order(node.right)
    visit(node)

# 层序 BFS
from collections import deque
def level_order(root):
    if not root: return
    q = deque([root])
    while q:
        node = q.popleft()
        visit(node)
        if node.left:  q.append(node.left)
        if node.right: q.append(node.right)
```

## 五、几个常用公式
- 二叉树中：**n₀ = n₂ + 1**（叶子数 = 度为 2 的节点数 + 1）
- 完全二叉树 n 个节点的高度 = ⌊log₂ n⌋ + 1
- 满二叉树深度 k 时节点数 = 2\^k - 1

## 六、二叉搜索树 (BST) 的插入与删除
### BST 性质回顾
- **左子树所有节点 \< 根 \< 右子树所有节点**
- 递归定义：每棵子树也是 BST
- 中序遍历得到升序序列
### 1. 查找
比根小往左，比根大往右，一直找到匹配或空节点。**平均 O(log n)，最坏 O(n)**。
```python
def search(node, key):
    if not node or node.val == key:
        return node
    if key < node.val:
        return search(node.left, key)
    return search(node.right, key)
```
### 2. 插入
**永远插入为一个新叶子**。找到应该在的位置，挂上去。
```python
def insert(node, key):
    if not node:
        return TreeNode(key)
    if key < node.val:
        node.left = insert(node.left, key)
    elif key > node.val:
        node.right = insert(node.right, key)
    # key == node.val 通常不重复插入
    return node
```
**示例**：依次插入 50, 30, 70, 20, 40, 60, 80
```plain text
        50
       /  \
      30   70
     / \   / \
    20 40 60 80
```
### 3. 删除 —— 三种情况
设要删除的节点为 `X`：
#### 情况 1：X 是叶子
**直接删掉**，父节点指向 null。
```plain text
删除 20：
    30            30
   /  \    →       \
  20  40            40
```
#### 情况 2：X 只有一个孩子
**用那个孩子顶替 X 的位置**。
```plain text
删除 30（只有右孩子 40）：
    50            50
   /  \    →     /  \
  30  70        40  70
    \
    40
```
#### 情况 3：X 有两个孩子（关键！）
**找一个合适的节点替代 X**，两种选法（任选其一）：
- **中序前驱**：左子树里的**最大值**（左子树最右节点）
- **中序后继**：右子树里的**最小值**（右子树最左节点）
**步骤**：
1. 找到后继（或前驱）
2. 把后继的**值**复制到 X
3. 递归删除后继节点（后继必然属于情况 1 或 2，简单）
```plain text
删除 50（有两个孩子），用后继 60 替代：

        50                60
       /  \      →       /  \
      30   70           30   70
     / \   / \         / \    \
    20 40 60 80       20 40   80
```
```python
def delete(node, key):
    if not node:
        return None
    if key < node.val:
        node.left = delete(node.left, key)
    elif key > node.val:
        node.right = delete(node.right, key)
    else:
        # 找到目标节点
        if not node.left:
            return node.right     # 情况 1/2
        if not node.right:
            return node.left      # 情况 2
        # 情况 3：找右子树最小值
        succ = node.right
        while succ.left:
            succ = succ.left
        node.val = succ.val
        node.right = delete(node.right, succ.val)
    return node
```
### BST 的痛点
**如果按有序顺序插入**（如 1, 2, 3, 4, 5），BST 退化为链表，操作变 O(n)：
```plain text
1
 \
  2
   \
    3
     \
      4
```
这就是需要**平衡树**的原因。

## 七、AVL 树 · 严格平衡
### 定义
AVL 是**自平衡的 BST**，满足：
**每个节点的左右子树高度差 ≤ 1**
这个差值叫**平衡因子 (Balance Factor)**：
```plain text
BF(node) = height(left) - height(right)  ∈ {-1, 0, +1}
```
一旦插入/删除让 BF 变成 ±2，就要**旋转**修复。
### 旋转 · 核心中的核心
旋转是**局部结构调整**，只动几个指针，保持 BST 性质不变，同时降低树高。
#### 1. 左旋 (Left Rotation) —— 处理右重（BF = -2）
当**右子树太高**时，把右孩子拎上来当根，自己降为左孩子。
```plain text
    A                    B
     \                  / \
      B       →        A   C
       \
        C
```
**指针操作**（以 A 为旋转点）：
```python
def rotate_left(A):
    B = A.right
    A.right = B.left    # B 的左孩子过继给 A
    B.left = A
    return B            # B 成为新的子树根
```
#### 2. 右旋 (Right Rotation) —— 处理左重（BF = +2）
当**左子树太高**时，把左孩子拎上来当根。
```plain text
        C                B
       /                / \
      B         →      A   C
     /
    A
```
```python
def rotate_right(C):
    B = C.left
    C.left = B.right
    B.right = C
    return B
```
### AVL 插入的 4 种失衡情况
设插入后失衡节点为 `X`，看**新节点插到了 X 的哪个子树的哪一侧**：
#### LL 型（左孩子的左子树插入） —— 单次右旋
```plain text
      X               Y
     /               / \
    Y      →        Z   X
   /
  Z（新）
```
**修复**：以 X 为轴**右旋一次**。
#### RR 型（右孩子的右子树插入） —— 单次左旋
```plain text
    X                   Y
     \                 / \
      Y      →        X   Z
       \
        Z（新）
```
**修复**：以 X 为轴**左旋一次**。
#### LR 型（左孩子的右子树插入） —— 先左旋后右旋
```plain text
      X               X                Z
     /               /                / \
    Y      →        Z       →        Y   X
     \             /
      Z（新）      Y
```
**修复**：先对 Y **左旋**，变成 LL 型，再对 X **右旋**。
#### RL 型（右孩子的左子树插入） —— 先右旋后左旋
```plain text
    X               X                  Z
     \               \                / \
      Y     →         Z      →       X   Y
     /                 \
    Z（新）             Y
```
**修复**：先对 Y **右旋**，变成 RR 型，再对 X **左旋**。
### AVL 特点
- **查找快**：树高严格 O(log n)
- **插入删除慢**：需要维护平衡因子和频繁旋转
- **适合**：读多写少的场景

## 八、红黑树 · 近似平衡
### 5 条规则
红黑树是弱平衡 BST，每个节点染红或黑，满足：
1. **每个节点非红即黑**
2. **根节点是黑色**
3. **叶子（NIL 空节点）是黑色**
4. **红节点的孩子必须是黑色**（不能有连续红色）
5. **任意节点到其所有后代叶子的路径上，黑节点数相同**（黑高相等）
由这 5 条能推出：**最长路径 ≤ 最短路径 × 2**，因此高度仍是 O(log n)。
### 与 AVL 的对比
| 维度 | AVL | 红黑树 |
| --- | --- | --- |
| 平衡性 | 严格（高度差 ≤ 1） | 弱（最长 ≤ 2×最短） |
| 查找 | 更快（树更矮） | 略慢 |
| 插入/删除 | 旋转多 | 旋转少，改颜色即可 |
| 适用 | 读多写少 | 读写均衡 |
| 实际应用 | 少 | 极广（Java TreeMap、C++ map、Linux 内核） |
### 插入
**新节点默认染红**（这样最不容易破坏规则 5）。然后看是否违反规则 4（父红且孩子也红）。
设新节点为 N，父为 P，祖父为 G，叔叔为 U。
#### 情况 1：P 是黑
✅ 没违规，结束。
#### 情况 2：P 是红，U 也是红
**变色**：P、U 染黑，G 染红。然后把 G 当作新的 N 递归向上处理。
```plain text
    G(黑)            G(红) ← 继续向上检查
   /   \    →       /   \
  P(红) U(红)      P(黑) U(黑)
  /                /
 N(红)            N(红)
```
#### 情况 3：P 是红，U 是黑（或不存在），且 N 是"外侧"
**一次旋转 + 变色**。
以 P 是 G 的左孩子、N 是 P 的左孩子为例（LL 型）：
1. 以 G 为轴**右旋**
2. **P 变黑、G 变红**
```plain text
      G(黑)              P(黑)
     /   \              /   \
    P(红) U(黑)   →    N(红) G(红)
   /                          \
  N(红)                        U(黑)
```
#### 情况 4：P 是红，U 是黑，且 N 是"内侧"
先旋转把它掰成情况 3，再按情况 3 处理。
LR 型：先对 P 左旋 → 变成 LL 型 → 按情况 3 处理。
### 删除
删除比插入复杂得多，核心思想：
1. 按 BST 规则找到实际要删的节点（有两孩子时转为删后继）
2. 如果**删的是红节点**：直接删，不破坏任何规则 ✅
3. 如果**删的是黑节点**：破坏了规则 5（少一个黑节点）→ 需要\*\*"双黑修复"\*\*（Double Black），通过兄弟节点的颜色和结构，走 4 种情况的旋转 + 变色来补上。
> 面试常问核心：**新插入的节点为什么默认染红？**
答：染红最多违反规则 4（父红子红），修复只是局部旋转/变色；若染黑必然破坏规则 5（全局黑高），修复代价大得多。
### 红黑树的实际应用
- **Java**：`TreeMap`、`TreeSet`、`HashMap`（链表长度 \> 8 转红黑树）
- **C++ STL**：`map`、`set`、`multimap`、`multiset`
- **Linux 内核**：进程调度 CFS、epoll 事件管理、虚拟内存区域管理
- **数据库**：一些内存索引

## 九、总结口诀
### 遍历口诀
- **前序**：根左右 → 复制/序列化
- **中序**：左根右 → BST 出有序序列
- **后序**：左右根 → 释放/合并结果
- **层序**：从上到下、从左到右 → 最短路径
### BST 删除口诀
- 无孩子：**直接删**
- 一个孩子：**孩子顶替**
- 两个孩子：**找后继替值，再删后继**
### 旋转口诀
- **LL → 右旋**
- **RR → 左旋**
- **LR → 先左后右**
- **RL → 先右后左**
### 选型口诀
- 读多写少、要极致查询 → **AVL**
- 读写均衡、工业常用 → **红黑树**
- 磁盘存储、范围查询 → **B+ 树**
- 完全二叉树 + 最值 → **堆**
