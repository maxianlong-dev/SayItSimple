# 图 (Graph)
> 从基础概念到遍历、最短路、最小生成树、拓扑排序，一次讲透。
---
## 一、图是什么
**大白话**：一堆点，点和点之间用线连起来，就是图。跟树的区别：
- 树**只有一个根**、**无环**、**每个节点一个爹**
- 图**没有根**、**可以有环**、**一个点可以连多个点**
树其实是图的一种特例（**无环连通图** = 树）。
```plain text
    A ─── B
    │  ╲  │
    │   ╲ │
    C ─── D
```
---
## 二、核心术语
### 1. 顶点 (Vertex) 和 边 (Edge)
- **顶点 V**：图里的点，也叫节点
- **边 E**：连接两个顶点的线
一个图记作 **G = (V, E)**。
### 2. 有向图 vs 无向图
**无向图**：边没方向，A-B 就意味着 A↔B 互通。
```plain text
A ─── B    朋友关系（互相）
```
**有向图 (Digraph)**：边有方向，A→B 不等于 B→A。
```plain text
A ──→ B    微博关注（单向）
```
### 3. 带权图 vs 无权图
**无权图**：边只表示"连通"。
**带权图 (Weighted)**：每条边带一个数值（距离、费用、时间）。
```plain text
A ──5── B    地图上 A 到 B 距离 5 公里
```
### 4. 度 (Degree)
- **无向图**：一个顶点连了几条边就是它的度
- **有向图**：分**入度 (in-degree)** 和**出度 (out-degree)**
	- 入度：指向它的边数
	- 出度：从它出发的边数
### 5. 路径 (Path) 和 环 (Cycle)
- **路径**：一串顶点，相邻两个之间有边
- **简单路径**：路径中顶点不重复
- **环 (Cycle)**：起点 = 终点的路径
- **无环图 (Acyclic)**：没有环
### 6. 连通性 (Connectivity)
**无向图**：
- **连通图**：任意两点都能互相到达
- **连通分量**：极大连通子图（把图拆成几坨互不相连的）
**有向图**：
- **强连通**：任意两点 u、v 都能 u→v 且 v→u
- **弱连通**：忽略方向后连通
- **强连通分量 (SCC)**：极大强连通子图
### 7. 稠密图 vs 稀疏图
- **稠密图**：边多，接近 V² 条
- **稀疏图**：边少，接近 V 条
这个区分决定了**用什么数据结构存图**。
### 8. 特殊图
- **完全图**：任意两点都有边（无向图有 V(V-1)/2 条边）
- **DAG (Directed Acyclic Graph)**：有向无环图 → 可拓扑排序
- **二分图**：顶点分两组，边只在组间不在组内 → 匹配问题

## 三、图的存储方式
### 1. 邻接矩阵 (Adjacency Matrix)
**是什么**：一个 V×V 的二维数组，`matrix[i][j] = 1` 表示 i→j 有边（带权就存权值）。
```plain text
    A B C D
  A 0 1 1 0
  B 1 0 0 1
  C 1 0 0 1
  D 0 1 1 0
```
**特点**：
- 空间 **O(V²)** — 不管有没有边都占位
- 查两点是否有边 **O(1)** — 直接下标访问
- 遍历一个点的邻居 **O(V)** — 要扫一整行
**适合**：稠密图、顶点数少、频繁查询两点关系。
### 2. 邻接表 (Adjacency List)
**是什么**：每个顶点挂一个链表/数组，存它的邻居。
```plain text
A → [B, C]
B → [A, D]
C → [A, D]
D → [B, C]
```
**特点**：
- 空间 **O(V + E)** — 只存实际存在的边
- 查两点是否有边 **O(度)** — 要扫链表
- 遍历邻居 **O(度)** — 直接遍历链表
**适合**：稀疏图、大规模图（社交网络、地图）—— **实际最常用**。
### 3. 边集数组 (Edge List)
**是什么**：直接列出所有边 `[(u,v,w), ...]`。
**适合**：Kruskal 最小生成树（要按权排序所有边）、Bellman-Ford。

## 四、图的遍历
### 1. 深度优先搜索 DFS
**大白话**：一条路走到黑，走不通再回头换一条。
**实现**：递归 或 栈。
```python
def dfs(graph, node, visited):
    if node in visited: return
    visited.add(node)
    visit(node)
    for neighbor in graph[node]:
        dfs(graph, neighbor, visited)
```
**用途**：
- 找连通分量
- 判断有无环
- 拓扑排序
- 求强连通分量（Tarjan）
- 迷宫、回溯
### 2. 广度优先搜索 BFS
**大白话**：一层一层往外扩散，像水波一样。
**实现**：用队列。
```python
from collections import deque

def bfs(graph, start):
    visited = {start}
    q = deque([start])
    while q:
        node = q.popleft()
        visit(node)
        for neighbor in graph[node]:
            if neighbor not in visited:
                visited.add(neighbor)
                q.append(neighbor)
```
**用途**：
- **无权图最短路径**（层数就是最短距离）
- 找所有距离 ≤ k 的点
- 网页爬虫的分层抓取
- 社交网络"N 度好友"
### DFS vs BFS 对比
| 维度 | DFS | BFS |
| --- | --- | --- |
| 数据结构 | 栈 / 递归 | 队列 |
| 空间 | O(高度) | O(宽度) |
| 找最短路 | ✗ | ✓（无权图） |
| 找一条路径 | ✓ 快 | ✗ 慢 |
| 检测环 | ✓ 好用 | 一般 |

## 五、经典算法
### 1. 最短路径
#### Dijkstra —— 单源最短路，不能有负权
**思想**：贪心 + 优先队列。每次从"待处理"中挑距离最小的点，用它更新邻居。
```plain text
初始化：dist[start] = 0，其他 = ∞
优先队列放入 (0, start)
循环：
    取出距离最小的点 u
    对 u 的每个邻居 v：
        if dist[u] + w(u,v) < dist[v]:
            dist[v] = dist[u] + w(u,v)
            入队 (dist[v], v)
```
**复杂度**：优先队列实现 O((V+E) log V)。
**适用**：地图导航、网络路由、游戏寻路。
#### Bellman-Ford —— 能处理负权
**思想**：暴力对所有边**松弛 V-1 次**。第 V 次还能松弛就说明有负环。
**复杂度**：O(V·E)，比 Dijkstra 慢，但能处理负权。
**适用**：金融套利（负环表示套利机会）、有负权边的路由。
#### Floyd-Warshall —— 多源最短路
**思想**：三重循环，动态规划。`dist[i][j]` 表示 i 到 j 经过前 k 个点的最短距离。
```python
for k in range(V):
    for i in range(V):
        for j in range(V):
            dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])
```
**复杂度**：O(V³)。
**适用**：顶点少（几百个）、要一次算出**任意两点**距离。
### 2. 最小生成树 (MST)
在**无向带权连通图**里找一棵树，包含所有顶点且边权和最小。
#### Kruskal —— 按边加
**思想**：所有边按权值排序，从小到大加，**用并查集判断是否成环**，不成环就加。
**复杂度**：O(E log E)。
**适用**：稀疏图。
#### Prim —— 按点加
**思想**：从任意点出发，每次加入一条"连接已选点和未选点的最小边"。类似 Dijkstra。
**复杂度**：优先队列实现 O((V+E) log V)。
**适用**：稠密图。
**用途**：网络布线成本最低、电力/水管规划、聚类分析。
### 3. 拓扑排序 (Topological Sort)
**前提**：有向无环图 (DAG)。
**是什么**：把所有顶点排成一个序列，使得**每条边 u→v，u 都排在 v 前面**。
**Kahn 算法（BFS 版）**：
```plain text
1. 找所有入度为 0 的点，入队
2. 出队一个点，加入结果
3. 把它的邻居入度减 1，减到 0 的入队
4. 重复直到队列空
5. 如果结果不包含所有点 → 有环
```
**用途**：
- **编译顺序**：Makefile、Maven/npm 依赖
- **任务调度**：先做前置任务
- **课程安排**：先修课
- **Excel 公式求值顺序**
### 4. 强连通分量 (SCC)
**Tarjan / Kosaraju 算法**，用 DFS 找到所有极大强连通子图。
**用途**：编译器优化、社交网络社区发现、死锁检测。
### 5. 二分图判定 & 匹配
**染色法**：BFS/DFS 交替染两种颜色，冲突就不是二分图。
**匈牙利算法**：求二分图最大匹配。
**用途**：任务分配、婚配问题、稳定匹配。
### 6. 网络流
**最大流 (Max Flow)**：源点 s 到汇点 t 能"流"多大的量。
**算法**：Ford-Fulkerson、Edmonds-Karp、Dinic。
**用途**：网络带宽、物流调度、图像分割、棒球淘汰问题。

## 六、复杂度速查
| 算法 | 时间复杂度 | 空间 | 备注 |
| --- | --- | --- | --- |
| DFS/BFS | O(V+E) | O(V) | 邻接表存图 |
| Dijkstra | O((V+E) log V) | O(V) | 不能负权 |
| Bellman-Ford | O(V·E) | O(V) | 能负权，可检测负环 |
| Floyd | O(V³) | O(V²) | 多源最短路 |
| Prim | O((V+E) log V) | O(V) | MST，稠密图 |
| Kruskal | O(E log E) | O(V) | MST，稀疏图 |
| 拓扑排序 | O(V+E) | O(V) | 仅 DAG |
| Tarjan SCC | O(V+E) | O(V) | 强连通分量 |

## 八、面试常问 & 记忆口诀
### 遇到问题先问三个问题
1. **有向还是无向？**
2. **带权还是无权？**
3. **可能有环吗？**
### 选算法口诀
- **无权最短路** → BFS
- **带权最短路，无负权** → Dijkstra
- **带权最短路，有负权** → Bellman-Ford
- **任意两点最短路** → Floyd
- **最小连通所有点** → Kruskal / Prim
- **依赖顺序、执行顺序** → 拓扑排序
- **判断有环** → DFS（三色标记）或 拓扑排序（有节点入度不为 0）
- **连通分量** → DFS / BFS / 并查集
### 存储选择口诀
- **稠密图、V 小** → 邻接矩阵
- **稀疏图、V 大** → 邻接表 ← 默认选择
- **要按边排序** → 边集数组
